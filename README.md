# Casa 3D: sol, luz, conforto e vento

Visualizador web interativo (three.js) de uma simulação ambiental de uma casa em Maringá, PR. Gerado automaticamente; veja a página publicada (português e inglês) e os relatórios em PDF na pasta `reports/`.

Interactive web viewer of an environmental simulation (sun, shadows, daylight, thermal comfort, wind, air-conditioning cost) of a house in Maringá, Brazil.

Página / page: https://jose-tissei.github.io/casa-simulacao-3d/
